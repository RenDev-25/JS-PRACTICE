TWO KINDS OF VARIABLE DECLARATION IN JAVASCRIPT

Using const and let in Modern JavaScript

When to Use var, let, or const?

  1. Always declare your variables.
  2. Use const if the variable should not be reassigned.
  3. Use const for arrays and objects when the reference should stay the same.
  4. Use let only when the variable's value needs to change.
  5. Avoid using var in modern JavaScript projects.
