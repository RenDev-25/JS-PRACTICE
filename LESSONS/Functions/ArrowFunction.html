JavaScript Arrow Functions

Arrow functions are a shorter way to write JavaScript functions. They use the arrow (=>) syntax and are commonly used in modern JavaScript development.

Example 1 - Basic Arrow Function

A simple arrow function that returns a message. 

const message = () => {
    return "Hello JavaScript";
};

Example 2 - Arrow Function Without Parameter

An arrow function that does not receive any value. 

const welcome = () => {
    return "Welcome Student";
};

Example 3 - One Parameter

An arrow function that accepts one parameter. 

const greet = name => {
    return "Hello " + name;
};

Example 4 - Multiple Parameters

An arrow function that uses multiple parameters. 

const add = (a,b) => {
    return a + b;
};

Example 5 - Short Return Arrow Function

Arrow functions can remove braces and return keyword when returning one value. 

const multiply = (a,b) => a * b;

Example 6 - Calculate Square

An arrow function that performs a mathematical calculation. 

const square = number => number * number;

Example 7 - Rectangle Area

An arrow function that uses multiple parameters to calculate an area. 

const area = (length,width) =>
length * width;

Example 8 - Full Name

An arrow function that combines two values and returns a string. 

const fullName = (first,last) => {

    return first + " " + last;

};

Example 9 - Check Even Number

An arrow function that checks if a number is even. 

const checkEven = number =>
number % 2 === 0;

Example 10 - Arrow Function with DOM

An arrow function that changes content using the DOM. 

const changeText = () => {

    document text

};

Example 11 - Arrow Function with One Parameter

An arrow function that receives a value and displays it. 

const changeText = (name) => {

    document text

};
