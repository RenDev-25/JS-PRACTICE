Named Function Expressions

Example 1 - Basic Named Function Expression

const message = function showMessage(){

    return "Hello JavaScript";

};

Example 2 - Named Function with Parameter

const greet = function sayHello(name){

    return "Hello " + name;

};

Example 3 - Named Function Returning Value

const add = function addition(a,b){

    return a + b;

};

Example 4 - Named Function Calculation

const square = function calculateSquare(number){

    return number * number;

};

Example 5 - Named Function with DOM

const display = function showResult(){

    document.getElementById("output5")
    .textContent = "Result Displayed";

};
